Tutorials
=========

Narrative routes through several subpackages at once. Every code line on
these pages is run by the documentation build.

- :doc:`course`: a seven-lesson guided course with objectives, prerequisites,
  and checkpoints.
- :doc:`life_of_a_payment`: one payment from a private key to a block, through
  a fork that undoes it and the reinclusion that restores it.
- :doc:`nonces_everywhere`: four different "numbers used once", and what goes
  wrong when each is reused.
- :doc:`hashes_everywhere`: six jobs SHA-256 does, and the property each one
  relies on.
- :doc:`who_do_you_trust`: the assumption behind every mechanism, and the
  experiment where it breaks.

Worked solutions to the gallery's exercises are in :doc:`/exercises/index`.
