Examples
========

This gallery walks through ``blockchainkit.fraud``, one experiment per
breakthrough on the :doc:`fraud history page </history/fraud_breakthroughs>`:
Ponzi schemes from Ponzi's own to Ethereum's and BitConnect; Benford's law;
proofs of reserves, liabilities and solvency, Mt. Gox and FTX; scam
contracts whose verified source deceives, from honeypots to the Squid Game
token, and ICO exit scams; the Willy bot, pump-and-dumps and wash trading;
and approval phishing and address poisoning.

Each script is self-contained and runs with
``python examples/fraud/<section>/<script>.py``.
