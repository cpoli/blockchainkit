Bitcoin Script
--------------

Spending conditions as loop-free stack programs: pay-to-public-key-hash and
hash time-locked contracts.

.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="Bitcoin does not record owners. Each coin carries a locking script, and spending it means supplying an unlocking script that makes the pair succeed. The standard lock, pay-to-public-key-hash, says: &quot;show a public key with this hash, and a signature by it over the spending transaction&quot;. Script is a Forth-like stack language with no loops, so a script of n operations runs at most n steps: Bitcoin needs no gas.">

Peter Todd&#x27;s OP_CHECKLOCKTIMEVERIFY (BIP 65, 2015) made the deadline enforceable in Script, and Poon and Dryja&#x27;s Lightning Network (2016) chains HTLCs with the same hash across many channels, so a payment either completes along the whole route or nowhere.">
