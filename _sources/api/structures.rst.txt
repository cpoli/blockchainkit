blockchainkit.structures
========================

.. include:: /_generated/nav/structures.rst

.. automodule:: blockchainkit.structures
   :no-members:

Merkle trees and proofs, signed transfers, blocks, ledger state, and cumulative-work fork selection.

Every public name below is re-exported by the subpackage: import it as
``bk.structures.<name>``. The plotting helpers are the exception: import them
explicitly from ``blockchainkit.structures.visualizers``, which loads Matplotlib.
