blockchainkit.economics
=======================

.. include:: /_generated/nav/economics.rst

.. automodule:: blockchainkit.economics
   :no-members:

Why participants behave honestly, how block space is priced, and how the
markets that contracts run can be exploited: focal points and oracles,
auctions and market scoring rules, block rewards and mining games, fee
markets, a constant-product exchange, a collateralized stablecoin, and
transaction ordering.

Every public name below is re-exported by the subpackage: import it as
``bk.economics.<name>``. The plotting helpers are the exception: import them
explicitly from ``blockchainkit.economics.visualizers``, which loads
Matplotlib.
