Examples
========

Runnable experiments for every subpackage, built from the scripts under
``examples/<name>/``. Each one includes assertions, a figure, a "What to look
for" guide, and an exercise. Download any of them as a Python script or a
Jupyter notebook, or run it in the browser with JupyterLite. The guided
:doc:`/tutorials/course` gives a learning order across subpackages.
