Experiments and notebooks
=========================

New readers can begin with :doc:`/start_here` and use :doc:`/glossary`
for unfamiliar terms. Each experiment includes a “What to look for” guide.

Read the historical motivation in :doc:`/history`, then run these experiments
in order. Each page includes source code, figures, observations, and an
exercise. Use the download links to obtain the Python script or Jupyter
notebook. All examples are small enough to run on a laptop without network
access after installation. Explicit keys and nonces are teaching fixtures.
