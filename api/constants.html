blockchainkit.constants#

Every consensus-relevant constant: hash domain tags, encoding bounds, and the default chain ID. Changing any of them changes hashes, signatures, or validation; see Exact conventions and model boundaries.

Consensus-relevant constants shared across blockchainkit.

Every hash domain tag, encoding bound, and default identifier lives here, so a change to one of them is visible as a change to the protocol. Changing any value changes hashes, signatures, or validation: update docs/source/protocol.rst, the tests, the examples, and CHANGELOG.md together.

>>> from blockchainkit import constants
>>> constants.UINT64_LIMIT == 2**64
True
