Examples#

This gallery walks through blockchainkit.structures, one experiment per breakthrough on the structures history page: double-entry ledgers and account nonces, Bloom filters, hash chains, Merkle trees and their pitfalls, linked and batched timestamps, unspent outputs, light clients, transaction ids, replay protection, sparse Merkle trees, and mountain ranges. The chain examples follow a payment through blocks, forks and reorganizations.

Each script is self-contained and runs with python examples/structures/<section>/<script>.py.
