Examples#

This gallery walks through blockchainkit.network, one experiment per breakthrough on the network history page: discrete-event simulation and logical clocks, epidemic gossip and reliable broadcast, random, small-world and scale-free peer graphs, Kademlia with its Sybil and eclipse attacks, block relay and forks, transaction privacy, and the CAP trade-off.

Each script is self-contained and runs with python examples/network/<section>/<script>.py.
