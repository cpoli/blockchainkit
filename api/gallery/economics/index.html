Examples#

This gallery walks through blockchainkit.economics, one experiment per breakthrough on the economics history page: focal points and Schelling oracles; Vickrey’s and Myerson’s auctions and Hanson’s market scoring rule; block rewards, the halving, fee-only mining and mining games; EIP-1559’s base fee; Dai, Uniswap and oracle manipulation; and priority gas auctions, sandwiches and proposer-builder separation.

Each script is self-contained and runs with python examples/economics/<section>/<script>.py.
