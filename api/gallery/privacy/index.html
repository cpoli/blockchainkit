Examples#

This gallery walks through blockchainkit.privacy, one experiment per breakthrough on the privacy history page: Chaum’s mix-nets and Tor’s onion routing; ring signatures, key images and stealth addresses; k-anonymity, address clustering and Monero’s traceability; CoinJoin, TumbleBit and Tornado Cash; and the hidden amounts of Zerocoin, confidential transactions, RingCT and Mimblewimble.

Each script is self-contained and runs with python examples/privacy/<section>/<script>.py.
