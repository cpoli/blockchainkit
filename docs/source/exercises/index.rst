Exercises
=========

Every gallery example ends with an exercise. These pages collect worked
solutions for a selection of them, one page per subpackage. Each solution
sits in a collapsed box, so you can try the problem first, and its code is
run by every documentation build.

.. grid:: 1 2 3 3
   :gutter: 2

   .. grid-item-card:: Cryptography
      :link: crypto
      :link-type: doc

      Discrete logs, factoring, forged shares, curve identities, nonce reuse,
      and birthday collisions.

   .. grid-item-card:: Ledgers and data structures
      :link: structures
      :link-type: doc

      Merkle proofs and duplicated leaves, mountain ranges, Bloom-filter
      privacy, hash chains, and replayed payments.

   .. grid-item-card:: Consensus
      :link: consensus
      :link-type: doc

      Byzantine rounds, Ben-Or, mining statistics, confirmations, quorums,
      stake splitting, and accountable safety.

   .. grid-item-card:: Networking
      :link: network
      :link-type: doc

      Lossy links, logical clocks, gossip on a ring, Bracha quorums, the
      connectivity threshold, eclipses, and short IDs.

   .. grid-item-card:: Execution
      :link: vm
      :link-type: doc

      RPN, stack depth, Forth words, busy beavers, atomicity, overflow checks,
      and gas prices.
